## 4. 목표 변경 사항

* **기존 목표 유지:** 1945 스트라이커즈 스타일의 세로 스크롤 슈팅 게임 개발이라는 초기 목표는 변경되지 않았습니다.
* **개발 일정 조정:** 초기 4주간은 수업 내용 이해와 에셋 준비에 집중하였고, 5주차부터 교수님께서 제공해주신 'DragonFlight' 프로젝트 코드를 기반으로 본격적인 개발을 시작했습니다. 이에 따라, **핵심 게임 플레이 요소(파워업 시스템, 다양한 적 패턴, 게임 오버 등) 구현에 더 집중**할 수 있도록 기존 개발 계획(`README.md` 초기 버전)을 수정하여 구체적인 주차별 목표를 재설정했습니다. 이는 목표 변경이 아닌, **효율적인 개발 진행을 위한 일정 현실화**입니다.

## 5. `MainScene` 주요 게임 객체 분석

`MainScene`은 게임의 주요 로직이 실행되는 핵심 공간으로, 다양한 게임 객체들을 레이어(`MainScene.Layer`)별로 관리하고 상호작용을 처리합니다. 현재 `MainScene`에 등장하거나 상호작용하는 주요 객체들은 다음과 같습니다.

| 객체 클래스             | 레이어 (`Layer`) | 역할 및 동작 (Class 구성 정보)                                                                                                                             | 상호작용 대상                                     | 핵심 코드 위치/설명                                                                                                                                                                 |
| :---------------------- | :--------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VertScrollBackground`  | `bg1`, `bg2`     | **(그림)** 배경 이미지 표시.<br>**(동작)** 지정된 속도(`speed`)로 이미지를 세로로 끊김 없이 스크롤하여 깊이감(Parallax)을 표현합니다.                                       | - (시각적 요소)                                   | `update()`: y 좌표를 `speed`와 `GameView.frameTime`에 따라 변경.<br>`draw()`: 현재 y 좌표 기준으로 이미지를 반복해서 화면에 그림 (`canvas.drawBitmap`).                                |
| `Fighter`               | `fighter`        | **(그림)** 플레이어 전투기 스프라이트 표시 (`R.mipmap.fighters`). 이동 방향 따라 프레임 변경.<br>**(동작)** 터치 드래그 위치로 **자유 이동(상하좌우)**. 자동 총알 발사. **파워 레벨(`powerLevel`) 관리**. | `Bullet` (생성), `Enemy` (충돌 예정), `PowerUpItem` (충돌) | `onTouch()`: 터치 좌표로 `targetX`, `targetY` 설정.<br>`update()`: `targetX`, `targetY`로 위치 직접 설정 (화면 경계 처리 포함), `fireBullet()`, `updateRoll()` 호출.<br>`fireBullet()`: 일정 간격으로 `Bullet` 생성 및 추가.<br>`increasePowerLevel()`: 파워 레벨 증가 (최대치 제한).<br>`getPowerLevel()`: 현재 파워 레벨 반환. |

| `Enemy`                 | `enemy`          | **(그림)** 적 비행기 애니메이션 스프라이트 표시 (`resIds` 배열 기반). 체력 게이지(`Gauge`) 표시.<br>**(동작)** 생성 위치에서 아래쪽(`dy = SPEED`)으로 직선 이동. 총알에 맞으면 체력 감소. (향후 패턴, 총알 발사, 아이템 드랍 추가 예정) | `Bullet` (충돌), `Fighter` (충돌 예정)                 | `init()`: 레벨, 위치, 체력 등 초기화.<br>`update()`: 아래로 이동, 화면 벗어나면 제거.<br>`decreaseLife()`: `Bullet` 충돌 시 호출되어 `life` 감소 처리, `life <= 0` 이면 `true` 반환.<br>`getX()`, `getY()`: 현재 위치 반환 (아이템 드랍용). |

| `Score`                 | `ui`             | **(그림)** 숫자 이미지를 사용하여 현재 점수 표시 (`R.mipmap.number_24x32`).<br>**(동작)** 점수 변경 시 부드러운 숫자 변화 애니메이션.                                       | - (UI 요소)                                       | `add()`: 내부 `score` 변수 증가.<br>`update()`: `displayScore`를 `score` 값으로 점진적 변경.<br>`draw()`: `displayScore` 값을 숫자 이미지로 변환하여 그림.                                |

| **(추가 예정)** `Explosion` | `(미정)`       | **(그림)** 폭발 애니메이션 스프라이트.<br>**(동작)** 생성 위치에서 애니메이션 1회 재생 후 제거. (`AnimSprite` 기반)                                                        | - (시각 효과)                                   | *(구현 예정)* |
