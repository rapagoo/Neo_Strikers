# 스마트폰 게임 프로그래밍 텀 프로젝트: 프로젝트 네오-스트라이커즈

## 1. 게임 컨셉

* **High Concept:** 화려하게 강화되는 전투기를 조종하여 몰려오는 적의 웨이브를 격파하는 재미를 극대화한 세로 스크롤 슈팅 게임. 플레이어는 파워업을 통해 점점 강해지는 자신을 체감하며, 시각적인 만족감과 함께 높은 점수를 획득하는 것을 목표로 합니다.
* **핵심 메카닉 (Core Mechanics):**
    * **플레이어 이동:** 화면 하단 영역 터치 드래그를 통한 전투기 좌우 이동.
    * **단계별 자동 발사 & 파워업:** 전투기는 자동으로 총알을 발사하며, 적 격파 시 나오는 파워업 아이템('P') 획득을 통해 공격력이 단계적으로 강화됩니다. 각 단계마다 총알의 개수, 패턴, 시각적 형태(`Sprite`)가 눈에 띄게 변화하여 성장을 체감할 수 있습니다.
    * **적 생성 및 웨이브:** 화면 상단에서 다양한 적들이 '웨이브' 형태로 등장하며 아래로 이동합니다. (`EnemyGenerator` 활용)
    * **충돌 처리:** 플레이어 총알과 적, 플레이어와 적, 플레이어와 아이템 간의 충돌을 감지하고 처리합니다. (`Collision Check/Handling` 활용)
    * **점수 시스템:** 적 격추 시 점수 획득 및 화면 표시. (빠른 연속 격파 시 추가 점수 고려 - 선택 사항)
    * **강화된 시각적 피드백:** 적 격파 시 만족감을 줄 수 있는 화려하고 큰 폭발 애니메이션(`Frame Animation`)을 사용하며, 파워업 시 공격 이펙트 변화를 명확하게 보여줍니다.
    * **게임 오버:** 플레이어가 적과 충돌 시 게임 종료 및 최종 점수, 재시작/종료 옵션 제공 (`AlertDialog`).

## 2. 개발 범위

* **플레이어 전투기:** 1종 (좌우 이동, 단계별 자동 발사 기능)
* **플레이어 파워업:** **최소 3단계** 구현 (예: Lv.1 기본샷, Lv.2 더블샷, Lv.3 와이드샷+보조무기). 각 레벨별 **차별화된 총알 스프라이트(Sprite)** 적용.
* **파워업 아이템('P'):** 1종 (`GameObject`로 구현, 적 격파 시 드랍)
* **적:** **최소 2종** (예: 일반 잡졸, 약간 튼튼한 중형기). **웨이브 형태로 등장**하도록 `EnemyGenerator` 설계.
* **배경:** 우주 배경 1종 (세로 Parallax 스크롤 효과 적용) - `Background Layering` 활용
* **UI:**
    * 게임 내 점수 표시 (`TextView` 또는 `CustomView` 내 그리기)
    * (권장) 현재 파워업 레벨 표시 UI
    * 게임 오버 시 `AlertDialog` (최종 점수, 재시작/종료 버튼)
* **시각 효과:**
    * 파워업 레벨별 **총알 스프라이트** 차별화.
    * **강화된 적 폭발 애니메이션** (`Frame Animation`, 1~2종).
    * (선택) 총알 명중 시 간단한 타격 이펙트 (`Sprite` 또는 `CustomView` 그리기).
* **핵심 시스템:**
    * 게임 루프 (`MainGame`, `Choreographer` 또는 `postDelayed`)
    * 객체 관리 (총알, 적, 아이템 재활용 - `Object Lifecycle Management`)
    * 충돌 처리 로직 (`Collision Check/Handling`)
    * 터치 입력 처리 (`Touch Event Handling`)
    * **단계별 파워업 로직** 구현.
* **(선택) 사운드:** 기본 배경음악, 발사음(레벨별 차별화 가능), 파워업 획득음, 폭발음.

## 3. 예상 게임 실행 흐름

![image](https://github.com/user-attachments/assets/e2864ecb-df87-41da-aa75-384f238e0bc0)

1.  **앱 실행:** 게임 타이틀과 "시작" 버튼이 있는 메인 화면 표시.
    * *(스케치: 타이틀 화면)*
2.  **게임 시작:** "시작" 버튼 클릭 시 게임 화면(Activity)으로 전환 (`Intent` 사용).
3.  **게임 플레이:**
    * 화면 하단 플레이어 전투기. 터치 드래그로 이동.
    * **자동으로 총알 발사. 'P' 아이템 획득 시 공격이 눈에 띄게 강력하고 화려해짐.**
    * 화면 상단에서 **적들이 웨이브를 이루며** 내려옴.
    * **적 격파 시 화려한 폭발 이펙트와 함께 'P' 아이템 드랍 가능성.**
    * 배경 이미지가 세로로 스크롤됨 (Parallax).
    * 화면 상단에 현재 점수 (및 파워업 레벨) 표시.
    * *(스케치: 파워업된 상태의 플레이어, 몰려오는 적 웨이브, 폭발 효과 강조된 게임 플레이 화면)*
4.  **충돌 발생:**
    * **총알-적 충돌:** 적이 **화려하게 폭발**하며 사라지고 점수 증가. 확률적으로 'P' 아이템 드랍. (`Collision Check`, `Frame Animation`)
    * **플레이어-'P' 아이템 충돌:** 아이템 획득, 파워업 레벨 증가 및 공격 패턴/시각 효과 변경.
    * **플레이어-적 충돌:** 플레이어 폭발하며 게임 오버 처리.
    * *(스케치: 적 폭발 / 아이템 획득 / 플레이어 폭발 장면)*
5.  **게임 오버:** `AlertDialog` 팝업 표시. 최종 점수와 "다시 시작", "종료" 버튼 제공.
    * *(스케치: 게임 오버 AlertDialog)*
